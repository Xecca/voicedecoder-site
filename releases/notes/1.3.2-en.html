Voice Decoder 1.3.2

File Transcription

  • Added support for .ts (MPEG-TS) video files: TV and IPTV recordings with MP2 or AC-3 audio are transcribed without ffmpeg
  • Files with a .ts extension that are not video (for example, TypeScript sources) are rejected with a clear error
  • Truncated or still-recording videos no longer crash the app or exhaust memory during audio extraction
  • Fixed a crash and lost files when dragging several files into the window at once

Updates & Support

  • The update server moved to voicedecoder.ponomarenko.dev, which fixes the “Update Error” when checking for updates
  • “Report an issue” now opens an email to support@ponomarenko.dev

Privacy & Security

  • Full file paths are no longer written to the system log
  • ffmpeg is restricted to local files: a media file can no longer make it access the network or read other files

Localization

  • Added missing Spanish and Russian translations
