Voice Decoder 1.3.0

Neural Text-to-Speech (Qwen3-TTS)

  • Added Qwen3-TTS 0.6B neural TTS engine — natural-sounding speech for English and Russian
  • 9 built-in voice presets (Chelsie, Ethan, and more)
  • Runs fully locally on Apple Silicon via MLX — no internet required
  • Generation parameters: temperature, top-p, repetition penalty, EOS bias
  • Automatic text chunking by sentences for stable long-text generation
  • Model pre-loading on app start for instant playback

Improvements

  • Play/Stop button state now correctly tracks the active transcription
  • Word highlighting works reliably when switching between recordings
